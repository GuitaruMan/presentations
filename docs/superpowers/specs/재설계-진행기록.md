### 1단계 결과 — 실물 확인 완료

브라우저로 직접 열어 확인했다.

- 교과군 규칙이 `[기술·가정/정보 ✕] [+ 교과군 추가 ▾] 교과에서 최소 [1] 과목` 한 줄로 읽힌다. 학생에게 보이는 문구는 아래 회색 칸에 라벨을 달아 분리했다. "둘 다 이름 같다"는 혼동이 사라졌다.
- 선수과목·과학중점의 과목이 전부 드롭다운이 됐고, 목록 끝에 `+ 직접 입력…`이 있다.
- 저장 전 미리보기가 작동한다. 안 바꾸고 누르면 "바뀐 것이 없습니다", 바꾸면 `기술·가정/정보 1과목 이상 → (최소 1 → 2)`를 보여주고 묻는다.
- "다시 불러오기"에 확인 대화상자가 붙어 있고, 눌러 보니 원래 값으로 돌아왔다.
- DB를 확인하니 학생용 문구의 가운뎃점, 선택슬롯의 학점 하위 객체, 유의사항 5개, 선수과목 16개가 모두 그대로였다.

고친 것: 유의사항 설명 문구가 정적 HTML과 렌더 함수에서 각각 그려져 두 줄로 겹쳐 보이던 것.

### 2단계 — 학교 교육과정 탭 + 학년도 관리 (완료)

**실물로 확인한 것**

- 열 순서가 `선택군 | 학기 | 성적방식 | 수능 출제`로 바뀌어, 학기와 수능 사이에 드롭다운이 끼었다. 헤더도 "수능 출제"로 명확해졌다.
- 헤더를 누르면 정렬된다. 기본은 원래 편성표 순서(공통국어1, 공통국어2…), 과목명을 누르면 가나다순(경제, 경제 수학…)에 `▲` 표시, 다시 누르면 역순. `원래 순서로` 버튼으로 돌아온다.
- 필터 3개(교과군·선택군·학년). 과학으로 좁히니 "106개 중 27개 보는 중".
- 과목명·선택군이 드롭다운이 됐다. 과목명은 144개 옵션(개설과목 + 마스터 + 구분선 + 직접 입력).
- 학년 고르기 카드에 과목 수, 학생 화면에 보이기 스위치, 지우기가 붙었다. `+ 새 학년도 만들기`도 있다.
- 새 학년도 폼이 뜬다 — 입학연도, 이름, 안내문, 대상, 본뜰 학년도. "폐강 표시는 복사하지 않습니다"까지 안내한다.
- 학생 화면에 보이는 학년도는 지우기가 잠겨 있고, 툴팁이 이유를 설명한다.

**실제 저장까지 확인**

시계를 맞춘 뒤 개설과목 표에서 학점을 4→5로 바꾸니 "저장됨"이 뜨고 DB에 반영됐다. 되돌리니 원상복구됐고, 전체 182행·빈 학기 28행·평가 분포가 그대로였다. 화면 조작에서 DB 저장까지 실제 경로로 확인한 셈이다.

## 겪은 문제 — 시계 오차

검증 중에 로그인이 `JWT issued at future`로 막혔다. 이 컴퓨터 시계가 서버보다 8초 앞서 있어, 방금 발급한 토큰을 서버가 미래의 것으로 본 것이었다. Supabase는 30초까지 허용하는데 로그인과 검증 사이에 차이가 더 벌어진 것으로 보인다.

`w32tm /resync`는 관리자 권한이 없어 거부됐고, 사용자가 직접 동기화하자 차이가 1초로 줄어 곧바로 해결됐다.

이 일로 알게 된 것 — 서버가 돌려주는 영어 오류가 화면에 그대로 나오면 무슨 일인지 알 수 없다. 시계 오차, 로그인 만료, 자격 증명 오류, 연결 실패, 권한 없음을 알아보고 무엇을 하면 되는지까지 한국어로 알려 주도록 고쳤다. 모르는 오류는 원문을 그대로 보여 준다.

## 판단 기록

**학년 선택을 로그인 직후 한 번으로 정한 이유.**
사용자가 두 안을 제시했다 — 탭마다 선택칸을 두거나, 로그인 첫 화면에서 고르거나. 후자를 택했다. 탭마다 두면 옮길 때마다 어느 학년인지 확인해야 하고 탭 사이가 어긋날 여지도 생긴다. 실제로 관리자는 "3학년 것을 손봐야지" 하고 들어오지 탭마다 다른 학년을 만지지 않는다.

**학생용 문구를 자동 생성으로 덮지 않기로 한 이유.**
지금 들어 있는 "국어·수학·영어 합계 14과목 이하"는 가운뎃점을 써서 다듬어진 문장이고, 학생 화면에 그대로 나간다. 자동 생성하면 이 표현이 뭉개진다. 대신 [문구 자동 만들기] 버튼을 두어 귀찮으면 한 번 누르고, 손보고 싶으면 손볼 수 있게 했다.

**과정구분을 읽기 전용으로 둔 이유.**
`일반`·`과학중점` 두 값은 편성표의 학기 표기(`{"일반":[1,2],"과학중점":[1,2]}`)와 맞물려 있다. 여기서 이름을 바꾸면 학기 정보가 통째로 어긋난다. 잠금을 풀어야 고칠 수 있게 했다.

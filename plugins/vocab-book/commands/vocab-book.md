---

vocab-book 스킬을 사용해 단어·숙어장을 만든다.

입력: $ARGUMENTS (교재 이미지 경로, 또는 단원/단어 목록 설명)

진행 순서:
1. 입력이 이미지면 Read 도구로 읽어 본문을 파악한다. 입력이 비어 있으면 무엇을 바탕으로 만들지 묻는다.
2. 학습자 학년과 원하는 쪽수를 확인한다 (말하지 않았다면 초등 고학년 · 4~6쪽을 기본값으로 쓰고 알린다).
3. 스킬의 JSON 스키마대로 항목을 정리한 뒤 scripts/make_pdf.py로 PDF를 만든다.
4. 생성된 쪽수를 확인해서 보고한다.
5. 사이트 게시는 사용자가 요청했을 때만 scripts/make_web.py와 scripts/publish.py로 진행한다.

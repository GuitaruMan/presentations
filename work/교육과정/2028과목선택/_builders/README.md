# 빌더

원본 자료(대학이 낸 PDF·엑셀)를 `../data/` 의 형식으로 옮기는 스크립트다.
사이트가 돌아가는 데는 필요 없다 — 자료를 다시 만들거나 고칠 때만 쓴다.

**원본 파일은 저장소에 두지 않는다.** 경로를 넘겨 쓴다.

```bash
pip install pymupdf
python build_3univ.py "<3개대학(아주대, 숭실대, 인하대) 선택과목 가이드북.pdf 경로>"
```

| 스크립트 | 하는 일 |
|---|---|
| `build_3univ.py` | 3개 대학 공동 가이드북 → 숭실대·아주대·인하대 자료 + 과목 사전 보강 |

## 다시 돌려도 안전하다

`build_3univ.py` 는 자기가 넣는 세 대학을 먼저 지우고 다시 넣는다. 과목 사전은
이미 있는 이름을 건너뛰므로 손으로 채운 설명이 지워지지 않는다. 돌린 뒤
`git diff` 가 비어 있으면 자료와 원본이 어긋나지 않았다는 뜻이다.

## 여기 없는 빌더

11개 대학(경북대·경희대·고려대·동국대·부산대·서울과기대·서울대·중앙대·충남대·
연세대·경기대) 자료를 만든 빌더는 저장소 밖 작업 폴더에 있다. 그 대학들의 자료를
고칠 일이 생기면 작업로그(2026-08-27 ~ 08-29)에 어느 스크립트가 무엇을 했는지
적혀 있으니 먼저 읽는다.

**여러 대학을 한 벌의 규칙으로 훑어 읽으려 하지 않는다.** 그렇게 만든 31개 대학
867개 모집단위 자료를 질이 떨어져 통째로 뺀 적이 있다(작업로그 2026-08-29).
빌더는 원본 표를 그대로 옮겨 적고 반복 규칙만 코드로 처리한다.

올라갈 내용 사용법

토큰을 쓰지 않으실 때는 JSON 내려받기로 받아 저장소의 data/ 폴더에 closed-2026.json 으로 덮어쓴 뒤 커밋하시면 됩니다.

폐강 표시는 편성표 원본을 건드리지 않습니다. 2차 정정에서 되살아나면 다시 눌러 해제하면 됩니다.

개설 현황 관리 사용법

이 페이지가 하는 일

학생 신청 결과 폐강된 과목을 학생 화면에서 지우는 일만 합니다. 편성표 자체는 건드리지 않으므로, 2차 정정에서 되살아나면 다시 켜면 됩니다.

위쪽 항목이 뜻하는 것

대상
어느 학년의 과목 선택인지 고릅니다. 학년마다 교육과정이 달라 열리는 과목도 다릅니다. 고르면 아래 목록이 통째로 바뀝니다.
단계
지금이 어느 시점인지 고릅니다. 고른 값이 학생 화면 맨 아래에 그대로 표시되어, 학생이 지금 보는 것이 언제 기준인지 알 수 있습니다.
갱신일
개설 현황을 정리한 날짜입니다. 역시 학생 화면 아래에 표시됩니다. 기본값은 오늘입니다.
폐강 모두 해제
표시한 폐강을 전부 지웁니다. 새 정정기간을 처음부터 시작할 때 씁니다.

과목 버튼 읽는 법

과목을 누르면 빨갛게 바뀌며 폐강으로 잡힙니다. 다시 누르면 풀립니다.

  • 학기가 다르면 별개입니다. 2학년 1학기 프랑스어와 2학년 2학기 프랑스어는 서로 다른 수업이므로 따로 눌러야 하고, 둘 다 누르면 2과목으로 셉니다.
  • 일반·과학중점 양쪽에 열리는 과목은 버튼이 하나입니다. 한 번 누르면 두 과정 모두 폐강되고 1과목으로 셉니다.
  • 한쪽 과정에만 열리는 과목은 버튼 옆에 일반 처럼 과정 이름이 붙습니다. 영어 독해와 작문이 그런 경우입니다.

반영하는 법 — 두 가지

① 토큰을 넣어 자동 커밋
토큰을 한 번 넣어 두면 지금 반영하기 버튼만 누르면 됩니다. 저장소에 바로 커밋되고, 1분쯤 뒤 학생 화면에 반영됩니다.

② 내려받아 직접 커밋
JSON 내려받기로 파일을 받아 저장소의 work/교육과정/2028과목선택/data/ 폴더에 덮어쓰고 커밋합니다.

토큰 만들기

  1. 깃헙 → Settings → Developer settings → Fine-grained personal access tokens → Generate new token
  2. Repository access는 presentations 하나만 고릅니다.
  3. Permissions에서 Contents: Read and write 만 켭니다.
  4. 만료일을 정하고 만든 뒤, 나온 토큰을 위 칸에 붙여 넣습니다.

토큰은 비밀번호와 같습니다. 공용 컴퓨터에서는 '이 기기에 저장'을 켜지 마세요. 권한을 이 저장소의 파일 쓰기로만 좁혀 두면 새어 나가도 피해가 이 저장소에 그칩니다. 의심되면 깃헙에서 즉시 폐기(revoke)하시면 됩니다.

이미 담아둔 학생은

폐강된 과목을 담아둔 학생이 페이지를 열면 안내가 뜬 뒤 그 과목이 자동으로 빠집니다.

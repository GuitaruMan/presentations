📚 vocab-book — 영어 단어·숙어장 만들기

교재 사진에서 단어·숙어를 뽑아 굿노트(아이패드)용 A4 PDF 단어장을 만드는 도구. Claude Code 플러그인, 클로드 데스크탑 스킬, 파이썬 스크립트 세 가지 형태로 받을 수 있다.

내려받기

🧩 vocab-book-plugin.zip Claude Code 플러그인 전체 (스킬 + 커맨드 + 스크립트 + 예시) 🖥️ vocab-book-desktop.zip 클로드 데스크탑용 스킬 — 설정 → 기능 → 스킬에 업로드 🐍 vocab_book.py 스크립트 한 파일 — 이것만 있어도 PDF 생성·게시가 전부 된다 📄 vocab-book-예시.json 데이터 형식 예시 (화상영어 Unit 7 — 단어 24 + 숙어 12)

쓰는 법

① Claude Code — 슬래시 명령 하나로 끝난다. 설치는 처음 한 번만. 
/plugin marketplace add GuitaruMan/presentations
/plugin install vocab-book@guitaruman-plugins
/vocab-book 교재사진1.jpg 교재사진2.jpg
위 zip을 따로 받지 않아도 된다. 인터넷이 안 되는 환경이면 zip을 풀어 /plugin marketplace add <폴더경로> 로 등록한다.
② 클로드 데스크탑 — Chrome 헤드리스가 없어 PDF를 직접 못 만들므로, 아티팩트로 만든 뒤 인쇄한다.
  1. vocab-book-desktop.zip 을 받는다
  2. 설정 → 기능(Capabilities) → 스킬 → 업로드
  3. 대화에 교재 사진을 올리고 "단어장 만들어줘"
  4. 아티팩트 ⋯ → 인쇄 → 대상 "PDF로 저장" (A4 세로, 배경 그래픽 켜기, 머리글·바닥글 끄기)
③ 스크립트만 — Claude 없이 JSON을 직접 고쳐 다시 뽑을 때. 
python vocab_book.py pdf  vocab.json 단어장.pdf
python vocab_book.py web  vocab.json 페이지.html --pdf 단어장.pdf --pdf-pages 6
python vocab_book.py push --category 주현이 --page 페이지.html --title "제목" --dry-run
JSON 형식과 자세한 설명은 vocab_book.py 맨 위 주석에 다 들어 있다.

필요한 것

항목용도
Python 3표준 라이브러리만 쓴다. 별도 설치 패키지 없음
Chrome 또는 EdgeHTML을 A4 PDF로 인쇄. 못 찾으면 CHROME_PATH 로 지정
git사이트에 게시할 때만 (push 명령)

결과물

쪽내용
1표지 — 제목, 항목 수, 공부 3단계, 이름·시작일 칸
2~단어 그룹마다 한 쪽 (12개까지, 카드 오른쪽에 필기용 점선 3줄)
다음숙어 그룹마다 한 쪽
마지막연습 ① 단어 뜻 쓰기 / 연습 ② 숙어 뜻 쓰기 + 빈칸 채우기
A4 세로, 크림 배경 + 파스텔 카드. 굿노트에서 애플펜슬로 바로 필기할 수 있게 여백을 뒀다.
